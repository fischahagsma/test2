## Сортировка пузырьком

Файл [`bubble_sort.py`](bubble_sort.py) содержит реализацию сортировки пузырьком (bubble sort).

### Как работает

Алгоритм многократно проходит по списку, сравнивает соседние элементы и меняет их местами,
если они стоят в неправильном порядке. После каждого прохода самый большой из оставшихся
элементов «всплывает» в конец списка — отсюда и название.

Если за очередной проход не было ни одного обмена, список уже отсортирован, и алгоритм
завершается досрочно.

### Сложность

| Случай                          | Время  | Память |
|---------------------------------|--------|--------|
| Лучший (список уже отсортирован) | O(n)   | O(n)   |
| Средний и худший                | O(n²)  | O(n)   |

Функция работает с копией списка, поэтому требует O(n) дополнительной памяти;
исходный список не изменяется. Сортировка устойчива: равные элементы сохраняют
свой взаимный порядок.

### Использование

```python
from bubble_sort import bubble_sort

print(bubble_sort([64, 34, 25, 12, 22, 11, 90]))
# [11, 12, 22, 25, 34, 64, 90]
```

Запуск примера из командной строки:

```bash
python3 bubble_sort.py
```
