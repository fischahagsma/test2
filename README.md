## Алгоритмы сортировки

В репозитории лежат 11 алгоритмов сортировки на Python, каждый в отдельном файле.
Все функции устроены одинаково:

- принимают любую последовательность и возвращают **новый** отсортированный список,
  а исходные данные не изменяют (поэтому каждой функции нужно ещё O(n) памяти на копию);
- сортируют по возрастанию;
- каждый файл можно запустить напрямую — он выведет пример сортировки.

```python
from merge_sort import merge_sort

print(merge_sort([38, 27, 43, 3, 9, 82, 10]))
# [3, 9, 10, 27, 38, 43, 82]
```

```bash
python3 merge_sort.py
```

### Сводная таблица

В столбце «Память» указана дополнительная память самого алгоритма, без копии входных данных.

| Алгоритм | Файл | Лучший | Средний | Худший | Память | Устойчивая |
|---|---|---|---|---|---|---|
| Пузырьком | [`bubble_sort.py`](bubble_sort.py) | O(n) | O(n²) | O(n²) | O(1) | да |
| Выбором | [`selection_sort.py`](selection_sort.py) | O(n²) | O(n²) | O(n²) | O(1) | нет |
| Вставками | [`insertion_sort.py`](insertion_sort.py) | O(n) | O(n²) | O(n²) | O(1) | да |
| Слиянием | [`merge_sort.py`](merge_sort.py) | O(n log n) | O(n log n) | O(n log n) | O(n) | да |
| Быстрая | [`quick_sort.py`](quick_sort.py) | O(n log n) | O(n log n) | O(n²) | O(n) | да* |
| Пирамидальная | [`heap_sort.py`](heap_sort.py) | O(n log n) | O(n log n) | O(n log n) | O(1) | нет |
| Шелла | [`shell_sort.py`](shell_sort.py) | O(n log n) | ≈O(n^1.5) | O(n²) | O(1) | нет |
| Подсчётом | [`counting_sort.py`](counting_sort.py) | O(n + k) | O(n + k) | O(n + k) | O(k) | да |
| Поразрядная | [`radix_sort.py`](radix_sort.py) | O(d·(n + b)) | O(d·(n + b)) | O(d·(n + b)) | O(n + b) | да |
| Расчёской | [`comb_sort.py`](comb_sort.py) | O(n log n) | ≈O(n log n) | O(n²) | O(1) | нет |
| Перемешиванием | [`cocktail_sort.py`](cocktail_sort.py) | O(n) | O(n²) | O(n²) | O(1) | да |

Обозначения: *n* — количество элементов, *k* — разница между максимальным и минимальным
значением, *d* — количество цифр в самом длинном числе, *b* — основание системы счисления (10).

\* Классическая быстрая сортировка «на месте» неустойчива; эта реализация раскладывает
элементы по новым спискам, поэтому порядок равных элементов сохраняется.

Сортировка подсчётом и поразрядная сортировка работают **только с целыми числами**
(в том числе отрицательными). Остальные алгоритмы подходят для любых сравнимых значений.

### Сортировка пузырьком

Файл: [`bubble_sort.py`](bubble_sort.py)

Алгоритм многократно проходит по списку, сравнивает соседние элементы и меняет их местами,
если они стоят в неправильном порядке. После каждого прохода самый большой из оставшихся
элементов «всплывает» в конец списка — отсюда и название. Если за очередной проход не было
ни одного обмена, список уже отсортирован, и алгоритм завершается досрочно.

### Сортировка выбором

Файл: [`selection_sort.py`](selection_sort.py)

На каждом шаге алгоритм находит минимальный элемент в неотсортированной части и меняет его
местами с первым элементом этой части. Отсортированная часть растёт слева на один элемент
за шаг. Делает всего O(n) обменов, но всегда O(n²) сравнений — даже на уже отсортированных
данных.

### Сортировка вставками

Файл: [`insertion_sort.py`](insertion_sort.py)

Алгоритм берёт элементы по одному и вставляет каждый на нужное место в уже отсортированной
левой части, сдвигая бо́льшие элементы вправо — так люди сортируют карты в руке. Очень быстрая
на почти отсортированных и небольших списках, поэтому её часто используют внутри более
сложных алгоритмов.

### Сортировка слиянием

Файл: [`merge_sort.py`](merge_sort.py)

Алгоритм «разделяй и властвуй»: список делится пополам, каждая половина рекурсивно
сортируется, затем две отсортированные половины сливаются в одну, на каждом шаге беря
меньший из первых элементов. Всегда работает за O(n log n), но требует O(n) дополнительной
памяти.

### Быстрая сортировка

Файл: [`quick_sort.py`](quick_sort.py)

Выбирается опорный элемент (здесь — случайный), и список разбивается на три части: элементы
меньше опорного, равные ему и больше него. Крайние части сортируются рекурсивно. Случайный
выбор опорного элемента делает худший случай O(n²) крайне маловероятным, а отдельная группа
равных элементов спасает от него на списках с большим числом повторов.

### Пирамидальная сортировка

Файл: [`heap_sort.py`](heap_sort.py)

Сначала из списка строится max-куча (двоичное дерево, где каждый родитель не меньше своих
потомков), так что максимум оказывается в начале. Затем максимум меняется местами с последним
элементом, куча уменьшается на один, а её свойство восстанавливается «просеиванием» вниз.
Гарантирует O(n log n) и не требует дополнительной памяти.

### Сортировка Шелла

Файл: [`shell_sort.py`](shell_sort.py)

Улучшенная сортировка вставками: сначала сортируются элементы, стоящие далеко друг от друга
(на расстоянии *gap*), потом шаг постепенно уменьшается вдвое до 1. Дальние перестановки
быстро переносят элементы ближе к их местам, и финальный проход вставками почти ничего не
двигает. Скорость зависит от выбора последовательности шагов.

### Сортировка подсчётом

Файл: [`counting_sort.py`](counting_sort.py)

Алгоритм не сравнивает элементы: он считает, сколько раз встречается каждое значение от
минимального до максимального, а затем выписывает значения по порядку нужное число раз.
Работает за линейное время, но годится только для целых чисел с небольшим диапазоном
значений — иначе массив счётчиков получится огромным.

### Поразрядная сортировка

Файл: [`radix_sort.py`](radix_sort.py)

Числа раскладываются по десяти «корзинам» сначала по последней цифре, затем по предпоследней
и так далее до старшего разряда (вариант LSD). Каждая раскладка сохраняет порядок предыдущей,
поэтому в конце список оказывается отсортированным. Отрицательные числа сортируются отдельно
по модулю и ставятся в начало в обратном порядке.

### Сортировка расчёской

Файл: [`comb_sort.py`](comb_sort.py)

Улучшенный пузырёк: сравниваются элементы на расстоянии *gap*, которое на каждом проходе
уменьшается в 1,3 раза. Это быстро убирает «черепах» — маленькие элементы в конце списка,
которые пузырёк переносит очень медленно. Когда шаг доходит до 1, алгоритм работает как
пузырёк и останавливается после прохода без обменов.

### Сортировка перемешиванием (шейкерная)

Файл: [`cocktail_sort.py`](cocktail_sort.py)

Двунаправленный пузырёк: проходы идут попеременно слева направо (самый большой элемент уходит
в конец) и справа налево (самый маленький уходит в начало). Границы неотсортированной части
сужаются с обеих сторон, а алгоритм завершается, как только проход обходится без обменов.

## Сайт на Flask

Сайт показывает работу всех алгоритмов: можно отсортировать свои числа одним алгоритмом
или сравнить все по времени работы.

Установка зависимостей и запуск:

```bash
pip install -r requirements.txt
python app.py              # или: flask --app app run
```

Затем откройте http://127.0.0.1:5000/. Для разработки (отладчик и перезапуск при изменениях)
запускайте `FLASK_DEBUG=1 python app.py` или `flask --app app run --debug` — только локально.

Страницы:

- `/` — форма сортировки и режим «Сравнить все»;
- `/algorithms/<key>` — страница алгоритма: сложность, описание и исходный код
  (например, `/algorithms/merge`);
- `POST /api/sort` — JSON API, например `{"algorithm": "merge", "numbers": [3, 1, 2]}`;
  ответ — `{"algorithm", "result", "elapsed_ms"}` или `{"error"}` с кодом 400.

Ограничения: не более 2000 чисел, числа по модулю не больше 10¹⁵; для сортировки подсчётом
разница между максимумом и минимумом — не больше 1 000 000.

Тесты:

```bash
pip install -r requirements-dev.txt
python -B -m pytest -q
```
